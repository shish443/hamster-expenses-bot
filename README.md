# Бот для учёта расходов на хомячков 🐹

Простой, удобный Telegram-бот для ведения личного учёта расходов на домашних хомячков или любых других питомцев. Быстро записывай траты, смотри статистику за разные периоды, удаляй ошибочные записи прямо через инлайн-кнопки.

## Основные команды

* **`/add <сумма> [описание]`** - добавить расход. Пример: `/add 150 корм` или `/add 320 клетка новая`
* **`/del <ID>`** - удалить запись по номеру. Пример: `/del 42`
* **`/calc [период]`** - посчитать сумму расходов. Доступные периоды: `day`, `week`, `month`, `quarter`, `halfyear`, `year`, `all` (работает и на русском: день, неделя, месяц)
* **`/list`** - последние 5 записей. Также поддерживаются: `/listWeek`, `/listMonth`, `/listQuarter`, `/listHalfYear`, `/listYear`, `/listAll`
* **`/help`**, **`/start`** - показать приветственное сообщение и список команд
* **`/info`** - информация об авторе и стеке
* **`/complaint <текст>`** - отправить жалобу или багрепорт админу

**Админ-команды:**

* `/admin` - общая статистика бота (Uptime, сообщения, ошибки, пользователи)
* `/admin <user_id>` - статистика по конкретному пользователю

## Быстрый запуск

### Вариант 1: Через start.go (интерактивный)

Самый удобный способ для локального развертывания:

```bash
git clone https://github.com/shish443/hamster-expenses-bot.git
cd hamster-expenses-bot
go run start.go

```

Скрипт поможет интерактивно создать `.env` файл, настроит окружение и запустит бота через Docker Compose.

### Вариант 2: Ручной запуск

1. Склонируй репозиторий:

```bash
git clone https://github.com/shish443/hamster-expenses-bot.git
cd hamster-expenses-bot

```

2. Создай файл `.env` в корне проекта:

```env
ApiTelegramBot=твой_токен_от_BotFather
ADMIN_ID=твой_telegram_id
DB_USER=hamster
DB_PASSWORD=твой_надёжный_пароль
DB_NAME=hamster_db

```

3. Запусти сборку:

```bash
docker compose up --build -d

```

## Особенности и функционал

* **Полная изоляция данных** - каждый пользователь видит и управляет только своими расходами.
* **Интерактивный интерфейс** - генерация инлайн-клавиатур для быстрого удаления записей и выбора периодов расчета в один клик.
* **Анти-спам система** - ограничение на флуд обычными текстовыми сообщениями вне команд.
* **Отказоустойчивость** - автоматическая инициализация базы данных, безопасные транзакции (Rollback при ошибках) и валидация ввода (лимит до 1 000 000 ₽, защита от длинных описаний).
* **Проксирование** - встроенная поддержка прокси через sing-box (`http://127.0.0.1:2080`) для стабильной работы.

## Структура проекта

* `main.go` - точка входа, инициализация зависимостей, запуск контекста
* `botLoop.go` - основной цикл обработки обновлений Telegram, обработка Callback-запросов от инлайн-кнопок, анти-спам
* `parser.go` - разбор входящих команд и аргументов
* `router.go` - маршрутизация команд по обработчикам
* `handlers.go` - бизнес-логика (добавление, удаление, вывод списков, подсчеты, админ-функции)
* `dataBase.go` - подключение и работа с PostgreSQL
* `stats.go` - сбор метрик, подсчет ошибок и uptime
* `start.go` - утилита для настройки конфигурации и автоматического старта

## Схема базы данных

Все расходы хранятся в таблице `expenses`:

* `id` - порядковый номер записи (автоинкремент).
* `user_id` - уникальный идентификатор пользователя в Telegram.
* `amount` - сумма транзакции.
* `description` - комментарий к расходу.
* `created_at` - точное время операции (UTC).
