# Бот для учёта расходов на хомячков 🐹

Простой и удобный Telegram-бот для ведения личного учёта расходов на домашних хомячков (или любых других питомцев).

Быстро записывай траты, смотри статистику за разные периоды и удаляй ошибочные записи.

## Основные команды

- **`/add <сумма> [описание]`** - добавить расход  
  Пример: `/add 150 корм` или `/add 320 клетка новая`

- **`/del <ID>`** - удалить запись по номеру  
  Пример: `/del 42`

- **`/calc [период]`** - посчитать сумму расходов  
  Доступные периоды: `day`, `week`, `month`, `quarter`, `halfyear`, `year`, `all` (или на русском: день, неделя, месяц и тд.)

- **`/list`** - последние 5 записей  
  Также поддерживаются: `/listWeek`, `/listMonth`, `/listQuarter`, `/listHalfYear`, `/listYear`, `/listAll`

- **`/help`** или **`/start`** - показать это сообщение

- **`/info`** - информация об авторе

- **`/complaint <текст>`** - отправить жалобу админу

**Админ-команды:**
- `/admin` - общая статистика бота
- `/admin <user_id>` - статистика по конкретному пользователю

## Быстрый запуск

### Вариант 1: Через start.go (самый удобный)

```bash
git clone https://github.com/shish443/hamster-expenses-bot.git
cd hamster-expenses-bot
go run start.go
```

Скрипт сам поможет создать `.env` файл, настроит всё необходимое и запустит бота через Docker Compose.

### Вариант 2: Ручной запуск

```bash
git clone https://github.com/shish443/hamster-expenses-bot.git
cd hamster-expenses-bot
```

Создай файл `.env` в корне проекта:

```env
ApiTelegramBot=твой_токен_от_BotFather
ADMIN_ID=твой_telegram_id
DB_USER=hamster
DB_PASSWORD=твой_надёжный_пароль
DB_NAME=hamster_db
```

Запусти:

```bash
docker compose up --build -d
```

## Особенности

- Полная изоляция данных - каждый пользователь видит только свои расходы
- Поддержка русского и английского названий периодов
- Docker + PostgreSQL + автоматическая инициализация БД
- Прокси через sing-box (при необходимости)
- Простая админ-панель

## Технологии

- **Go** 1.21+
- **PostgreSQL**
- **go-telegram-bot-api**
- **Docker** + **Docker Compose**

## Структура проекта

- `main.go` - точка входа
- `botLoop.go` - основной цикл обработки сообщений
- `parser.go` - разбор команд
- `router.go` -маршрутизация
- `handlers.go` - бизнес-логика
- `dataBase.go` - работа с БД
- `stats.go` - статистика и uptime
- `start.go` - удобный интерактивный запуск

## Схема базы данных

Все расходы хранятся в таблице `expenses`, у неё простая структура:

* `id` - порядковый номер записи.
* `user_id` - уникальный идентификатор пользователя в Telegram.
* `amount` - сумма денег.
* `description` - на что именно ушли деньги.
* `created_at` - точное время операции.
