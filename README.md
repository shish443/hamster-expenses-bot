# Бот для учёта расходов на хомячков 🐹

Простой Telegram-бот, который помогает следить за бюджетом на домашних питомцев. Сюда можно быстро скидывать траты, проверять статистику за разное время и убирать ошибочные записи.

## Команды бота

* **/add** - зафиксировать расход.
Пример: `/add 150 корм` или `/add 320 клетка новая`
* **/del** - удалить запись по её номеру.
Пример: `/del 42`
* **/calc** - посчитать общую сумму за нужный период.
Доступные варианты: `день`, `неделя`, `месяц`, `квартал`, `полгода`, `год`, `все`
* **/list** - показать последние 5 записей.
Посмотреть историю за конкретный отрезок времени можно через команды `/listWeek`, `/listMonth`, `/listQuarter`, `/listHalfYear`, `/listYear` и `/listAll`
* **/help** или **/start** - открыть подсказку и список команд.
* **/info** - пара слов про автора.

Чужие траты никто не увидит. База данных разделяет пользователей по их Telegram ID, так что ваши данные защищены.

## Быстрый запуск

### С помощью Docker Compose

Сначала скопируйте репозиторий себе на компьютер и перейдите в папку проекта:

```bash
git clone <ссылка-на-репозиторий>
cd hamster-expenses-bot

```

Затем создайте текстовый файл `.env` прямо в корневой папке и укажите там свои настройки:

```env
ApiTelegramBot=твой_токен_от_BotFather
DB_USER=hamster
DB_PASSWORD=твой_надёжный_пароль
DB_NAME=hamster_db

```

Теперь поднимите контейнеры одной командой:

```bash
docker compose up -d

```

После этого бот сам запустится и создаст нужные таблицы в PostgreSQL.

### Обычный запуск для разработки

Если хотите запустить код напрямую, вам понадобятся установленные Go версии 1.21 или новее и база данных PostgreSQL.

```bash
go mod download
go run .

```

## Устройство проекта

Код разбит на несколько файлов, чтобы в нём было проще ориентироваться:

* `main.go` - точка старта приложения.
* `parser.go` - отвечает за разбор сообщений и поиск команд.
* `router.go` и `handlers.go` - содержат логику ответов бота.
* `dataBase.go` - отвечает за связь с базой данных.
* `init.sql` - скрипт, который создаёт таблицу при первом старте.
* `Dockerfile` и `docker-compose.yml` - инструкции для сборки в контейнере.

## Что внутри

* Язык программирования **Go**
* База данных **PostgreSQL**
* Библиотека **go-telegram-bot-api** для работы с мессенджером
* Инструменты **Docker** и **Docker Compose**

## Схема базы данных

Все расходы хранятся в таблице `expenses`, у неё простая структура:

* `id` - порядковый номер записи.
* `user_id` - уникальный идентификатор пользователя в Telegram.
* `amount` - сумма денег.
* `description` - на что именно ушли деньги.
* `created_at` - точное время операции.
