# Проект

## Telegram-бот

### Функционал Telegram-бота

1.  Уметь считать расходы на хомячков за любой период.
2.  Уметь красиво выводить данные.
3.  Полная изоляция данных по `UserID` (каждый видит и управляет только своими записями).
4.  Хранить все введённые данные (привязанные к конкретному пользователю, без пересечений).
**Примечание при разработке -** Добавлена полноценная поддержка встроенной клавиатуры.
### что используем
1) ЯП-го
2) база данных-PostgreSQL
3) виртуализация-докер

#### start.go
**Примечание при разработке -** решил создать файл, который сам все развернет за пользователя-удобство и гарантия, что пользователь что-то не сломает

#### main.go

*   Получает API ключ из ENV файла.
*   Инициализирует бота.
*   Запускает основной цикл обработки (передаёт управление в botLoop.go).

#### parser.go
*   превращает сырое обновление в структурированную команду
*   Извлекает UserID и ChatID из update.Message.
*   Выделяет команду (убирает /, приводит к нижнему регистру).
*   проверяет не пустое ли сообщение, есть ли текст.

#### types.go
*   тупо хранит все структуры

#### botLoop.go
*   запускает цикл получения сообщений
*   Игнорирует nil сообщения, пустой текст, сообщения от других ботов.
*   Отправляет отфильтрованное обновление в parser.go.
*   Если парсинг вернул ошибку формирует ответ-подсказку пользователю ("Введите /help для списка команд").
*   Отправляет успешный результат в router.go
*   Отправляет ответ в тот же чат (ChatID) с привязкой к исходному сообщению (ReplyToMessageID).

#### keyboards.go
**Примечание при разработке:** Новый файл. Содержит: 
- `getMainKeyboard()` -главное меню
- `getCalcKeyboard()` -выбор периода 
- `createDeleteKeyboard()` - динамические кнопки удаления

#### router.go
*   Принимает команду.
*   Определяет команду через switch.
*   Передает в обработчики ТОЛЬКО нужные аргументы + обязательный UserID для изоляции ЛК.
*   Возвращает готовый текстовый ответ.
    ##### Команды:
        /start, /help - приветствие, список команд, объяснение ЛК.
        /add <сумма> [описание] - вызывает handleAdd.
        /del <id_записи> - вызывает handleDelete.
        /calc [период] - вызывает handleCalc.
            доступные периоды будут: день,неделя,месяц,квартал (3 месяца), полгода, год,в все время
        /list - показать последние 5 записей.
        /listWeek - показать все записи за месяц
        /listMonth - показать все записи за месяц
        /info - выводит данные о разработчике вызывает InfoAuthor
        default - "Команда не распознана. Введите /help".

#### handlers.go
    Start,Help - приветствие, список команд, объяснение ЛК.
    Add <сумма> [описание] - добавляет запись в базу данных.
    Del <id_записи> - удаляет запись.
    Calc [период] - считает все расходы за период.
        доступные периоды будут: день,неделя,месяц,квартал (3 месяца), полгода, год,в все время
        Периоды считаются автоматически по времени UTC если день ну и соответсвенно +6 дней если неделя+ 364 дня если год и тд
    List - обращается к базе за последними 5 аписями пользователя и отдает их. Если записей <5 выдает все что есть
    ListWeek/ListMonth/ListQuarter/ListHalfYear/ListYear - обращается к базе за "период" данными пользователя и отдает их. В любом случае отдает все что есть
    InfoAuthor - выводит информацио об авторе
